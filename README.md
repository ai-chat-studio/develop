# Text Mirror MVP v0.2

Тестовая схема двух окон.

## Протокол ответа

Полный текст имеет формат:

```text
777ROCK777
English content for viewers.
777END777

Русский:
Русская часть для владельца.
```

Сервер извлекает только текст между `777ROCK777` и `777END777`.

## Окна

После запуска:

- Studio: `http://SERVER_IP:3000/studio.html`
- Live: `http://SERVER_IP:3000/live.html`

`/` автоматически открывает Studio.

## Запуск

```bash
npm install
npm start
```

или:

```bash
PORT=3000 npm start
```

## Проверка

1. Открой `/studio.html`.
2. Во второй вкладке открой `/live.html`.
3. В Studio нажми `Вставить пример`.
4. В Live должен появиться только английский текст.
5. Измени английский блок в Studio — Live обновится в реальном времени.

## Важно

Это MVP для проверки механики:

- без авторизации;
- без базы данных;
- состояние хранится в RAM;
- после перезапуска Node.js состояние сбрасывается;
- любой, кто знает URL Studio, может менять текст.

Следующий этап: read-only token для Live, комнаты с ID, история сообщений и автоматическая передача текста из локального клиента.
